# IDFIS Product Readiness Checklist

To maintain the elite standard of the IDFIS brand, no product should be published to the live storefront unless it meets a score of **90/100** on this readiness checklist. 

This checklist must be utilized by store admins and content teams prior to toggling a product from "Draft" to "Active".

## 1. Visual Presentation
- [ ] **Minimum 6 Images:** The product has at least 6 high-definition, editorial-quality images.
- [ ] **Aspect Ratio:** Images are consistent (e.g., 3:4 portrait for apparel/accessories).
- [ ] **Detail Shots:** Includes close-ups of texture, weave, or craftsmanship.
- [ ] **Packaging Shot (Optional but Recommended):** Shows how the item will be packaged.
- [ ] **Alt Text:** Every image has descriptive SEO alt text (e.g., "Handwoven Crimson Pashmina with Zari Border").

## 2. Core Product Data
- [ ] **Product Title:** Clear, premium, and descriptive.
- [ ] **Product Story (Description):** A rich, emotive paragraph detailing the inspiration, origin, and effort behind the piece. No placeholder "lorem ipsum".
- [ ] **Price:** Set correctly for the primary market.
- [ ] **Compare-at Price:** ONLY use this if it represents a genuine, verifiable discount. Do not fake discounts.
- [ ] **SKU:** Assigned for every variant.
- [ ] **Inventory:** Accurate stock counts are assigned to the correct location.

## 3. IDFIS Custom Metafields
All metafields must be filled where applicable:
- [ ] **Craft Region & State:** E.g., Srinagar, Jammu & Kashmir.
- [ ] **GI Status:** Is it Verified GI, Inspired, or N/A?
- [ ] **Material Composition:** E.g., 100% Cashmere.
- [ ] **Care Instructions:** Clear washing/storing directions.
- [ ] **Packaging Tier:** Assigned 1 through 5.
- [ ] **Fragility Level:** Low, Medium, High.
- [ ] **Return Eligibility:** Clearly stated (e.g., "Eligible for 7-day return" or "Final Sale").

## 4. International Logistics Data
Critical for Phase 1 weight-based shipping and Phase 3 automated customs:
- [ ] **Weight:** Accurate base weight entered in Shopify. (Adjusted for packaging tier volumetric weight if necessary for Phase 1).
- [ ] **Country of Origin:** Set to India (IN).
- [ ] **HS Code:** Harmonized System code entered for international customs clearance.

## 5. SEO Configuration
- [ ] **SEO Title:** Optimized for search engines.
- [ ] **SEO Description:** A compelling meta description under 160 characters.
- [ ] **URL Handle:** Clean and readable (e.g., `crimson-pashmina-coat`).

## 6. Final Review
- [ ] Preview the product on **Desktop**.
- [ ] Preview the product on **Mobile** (check swipe galleries and font sizes).
- [ ] Add product to cart to verify variant selection works.
